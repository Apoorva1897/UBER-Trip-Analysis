# UBER-Trip-Analysis

This project provides a comprehensive analysis of Uber trip data to uncover insights around booking behavior, revenue generation, trip efficiency, and operational trends. Built in **Power BI**, this solution combines advanced **data modeling**, **dynamic DAX measures**, and **interactive dashboards** to drive informed decision-making.

## 📊 Dashboards Overview

### 1. Overview Analysis
- Total Bookings, Revenue, Avg. Trip Distance & Time
- Booking breakdown by **payment type** and **trip type (Day/Night)**
- **Vehicle type analysis**: Most used & highest revenue contributors
- Top pickup and drop-off locations
- Most preferred vehicle by location

### 2. Time Analysis
- Booking trends by **pickup time (10-min intervals)**
- Weekday vs Weekend ride behavior
- **Heatmap** of bookings by hour & day
- Metrics: Total Bookings, Booking Value, Trip Distance (Dynamic toggle)

### 3. Details Tab
- Granular trip-level data (Trip ID, Location, Vehicle, Fare, etc.)
- **Drill-through enabled**: Right-click from any dashboard view
- Summary statistics across 100K+ trips

## Key Features & Skills Demonstrated

- **Star Schema Data Modeling**
- **Disconnected tables** for dynamic measure switching
- **Advanced DAX**: dynamic titles, conditional formatting, custom calculations
- **Bookmarks & Tooltips** for UX enhancement
- Time Series & Location-Based Analysis
- Data export, slicer reset, and enhanced user interaction

##  Data Source
- Simulated Uber trip dataset with fields like:
  - Trip ID, Pickup Time, Vehicle Type, Payment Mode, Distance, Booking Value, etc.
